Usage and configuration

The full logo should be used when there is room for the wordmark and service line. The standalone fav icon should be used at small sizes or when the brand name appears nearby.

  • Minimum full-logo width: 220 px for web, 1.75 in for print.
  • Clear space: keep at least the height of the small dot around all sides.
  • Light backgrounds: use the color or black/white version.
  • Dark backgrounds: use the reverse version.
